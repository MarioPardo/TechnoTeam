# Backlog (Future Ideas)

These are out of scope for v1 but worth revisiting:

- **Event editing** — currently anyone can edit any event; add a simple edit-password per event
- **RLS / Supabase auth** — proper row-level security if data privacy becomes a concern
- **Cross-event groups** — a persistent crew that can plan across multiple festivals
- **Conflict detection** — warn when two picked performances overlap in time
- **Schedule export** — export your personal picks as iCal / PDF
- **Push notifications** — notify group members when someone joins or picks a set
- **Map view** — show stage locations on a festival map
- **Mobile app** — PWA or React Native wrapper
- **Comments on performances** — leave notes like "Meet at the barrier"
- **Emoji reactions on performances** — quick reactions without full plans
